# Лендинг «Т-Инвест: все портфели в Google Таблице и Telegram-боте»

Статическая страница без фреймворков и сборки. Три файла: `index.html`, `styles.css`, `script.js` + папка `images/`.

## Как запустить

Просто откройте `index.html` в браузере — работает без сервера и без интернета (кроме системного шрифта, внешних зависимостей нет).

Для публикации — загрузите все файлы (включая папку `images/`) на любой статический хостинг: GitHub Pages, Netlify, Vercel, обычный хостинг по FTP. Файл должен называться именно `index.html`, чтобы открывался по умолчанию.

## Что нужно заменить перед публикацией

### 1. Скриншоты
Все картинки лежат в `images/`. Названия файлов соответствуют тому, что на них изображено (`1table.png` — лист «Итого», `5rub.png` — команда /rub, и т.д.). Чтобы заменить — положите новый файл с тем же именем поверх старого, либо поменяйте путь в `src="images/..."` в `index.html` на новый.

Не хватает одного кадра: скриншота настроек токена Т-Инвестиций с выбранным «Только просмотр» (упоминался в ТЗ как `screen-6-token.png`) — в присланном архиве его не было. Блок «Безопасно ли это» сейчас показывает скриншот листа «Управление» вместо него (`images/3checkbox.png`). Если добавите нужный скриншот — замените `src` в `index.html` в секции `id="security"`.

Есть также файл `7guide_scroll.gif` в исходном архиве (анимация прокрутки гайда, ~8 МБ) — в лендинг сознательно **не включён**, чтобы не замедлять загрузку (в ТЗ было требование «быстрее 2 секунд на 3G»). При желании можно добавить его отдельно, но тогда стоит сжать или добавить `loading="lazy"`.

### 2. Ссылка на оплату
Сейчас все кнопки ведут на `#price` (якорь на блок с ценами) — отдельного платёжного шлюза в ТЗ не было указано. Чтобы кнопки вели на реальную оплату, замените `href="#price"` на вашу ссылку (например, на ЮKassa, Тинькофф Кассу или Telegram-бота с оплатой) в `index.html`:
- кнопка в шапке
- кнопка в hero
- финальная кнопка `ЗАБРАТЬ ГАЙД ЗА 990 ₽`

### 3. Цены
В `index.html`, секция `id="price"` — три карточки с числами `990 ₽`, `1 490 ₽`, `1 990 ₽`. Меняются прямо в тексте.

### 4. Счётчик мест
В `script.js`, самая первая строка:
```js
const seatsLeft = 47;
```
Поменяйте число — обновится везде на странице автоматически. Обновляется вручную, никакой базы данных нет (как и просили в ТЗ).

### 5. Реквизиты и ссылки в подвале
В `index.html`, секция `<footer class="site-footer">` в самом низу:
- «ИП Иванов И.И. · ИНН 000000000000» — замените на свои
- ссылки «Оферта» и «Политика конфиденциальности» сейчас ведут на `#` (никуда) — впишите реальные
- «Поддержка @your_support_bot» — замените на свой контакт

### 6. Telegram в шапке/логотип
Логотип (`images/logo.png`) и текст рядом с ним — в `index.html`, тег `<a class="brand">` в самом начале `<body>`.

## Технические детали

- Цвета заданы CSS-переменными в начале `styles.css` (`:root`) — `--navy`, `--yellow` и остальные. Поменять фирменный цвет можно в одном месте.
- Брейкпоинты: 480px, 768px, 1200px — медиа-запросы в конце `styles.css`.
- FAQ-аккордеон, счётчик мест, плавный скролл, карусель скриншотов гайда и анимация появления блоков — всё в `script.js`, без внешних библиотек.
- Если картинка не загрузится (неверный путь или файл удалён) — вместо неё покажется серый блок с подписью из `alt`, а не сломанная иконка браузера.
